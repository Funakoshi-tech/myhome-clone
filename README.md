# My Home Clone

ブラウザで動く、完全ローカル完結型の **3D間取り・家具配置シミュレーター**。
注文住宅の自己検討ツール。将来的に **日射・日当たりシミュレーション** を独自機能として追加予定。

> 「マイホームクラウド」「住宅スキャン」は他社登録商標。本プロジェクトは個人利用で、名称は **My Home Clone / マイホームクローン** を用います。商用配布はしません。

## 技術構成

- 純粋なフロントエンドのみ。**ビルドツール・バンドラ不要**（Vite/webpack なし）。
- ES Modules（`type="module"`）でファイル分割。
- 3D は **Three.js** を CDN + importmap で読み込み（npm 不要）。
- 永続化は **LocalStorage 自動保存** ＋ **JSON エクスポート/インポート**。
- 外部送信・サーバ通信は一切なし（完全ローカル）。Three.js の CDN 取得のみネット接続が必要。

## 起動方法

VS Code / Cursor の **Live Server**（Port 5500 想定）で `index.html` を開くだけ。
または任意の静的サーバで配信:

```bash
python3 -m http.server 5500
# → http://localhost:5500/
```

※ `file://` 直開きは ES Modules / importmap の制約で動かないため、必ずローカルサーバ経由で開いてください。

## 開発時の静的チェック（任意）

ランタイムは引き続き npm 不要です。コード変更後に **構文エラーや変数の二重宣言** を検出するには、開発用に ESLint を使えます:

```bash
npm install   # 初回のみ（devDependencies のみ）
npm run lint
npm test      # 敷地ロジックなどの単体テスト（Node 標準の node:test。追加依存なし）
```

`no-redeclare` などにより、同一スコープ内の `const` 重複（プラン新規作成不能の原因になりやすい）をコミット前に検出できます。

## 座標・単位の規約

- 内部単位は **mm**。`X`=間口（左右）、`Z`=奥行（上下）、3D の `Y`=高さ。Three.js の Y-up 右手系に一致。
- 1マス = **1P = 910mm**。スナップ = `910 / snapDivisions`（既定 4 = 0.25P / UIで 0.5P・0.25P 切替）。
- 面積はシューレース公式で算出し m² に換算。畳数 = 面積(m²) ÷ `meta.tatamiM2`（既定 1.62）。
- 図面表示は「12.4㎡（7.6帖）」形式。

## 使い方（フェーズA）

1. 上部で **2D / 3D** とフロア **1F / 2F / 3F** を切替。
2. 左の **ツール**で操作を選択:
   - **部屋を描く**: 種別を選び、作図エリアでドラッグして矩形の部屋を作成（壁は外周に自動生成）。
   - **家具を置く**: 家具を選びクリックで配置。
   - **選択 / 移動**: 部屋・家具をクリックで選択、ドラッグで移動。`Del` 削除、`R` 家具回転。
     選択中の家具を右クリック（または短クリック）すると、**左右反転・上下反転**・削除のメニューが出る（反転は家具自身の向き基準の鏡像で、2D・3D に反映）。
   - **画面移動**: ドラッグでパン（ホイールでズーム）。
   - **敷地を描く**（左の「敷地」パネル）: 下絵に沿って頂点を順にクリック → `Enter` か始点クリックで確定（`Shift` で 45° 刻み、右クリック/`Backspace` で直前の点を取り消し、`Esc` で中止）。確定後は枠線をクリックして選択し、プロパティで **辺の長さを数値指定**、頂点のドラッグ、右クリックでの頂点追加/削除ができる。辺の長さ・内角・面積（㎡/坪）を常時表示するので、下絵の縦横比がおかしくても実寸に合わせて書き直して下絵を非表示にできる。敷地に接する壁は外壁として扱われる。
3. 各部屋に **面積㎡と帖** を自動表示。
4. **3D** で壁を天井高まで立ち上げて立体表示（OrbitControls で視点操作）。**内観モード**で160cm目線の一人称歩行（右上ミニマップ・左下で階ワープ）。
5. 変更は **自動で LocalStorage 保存**。**JSON書出 / 読込** とプランの **新規・複製・削除** が可能。

## ロードマップ

- **フェーズA（実装済）**: 2D作図・面積/帖・家具・階段・3Dビュー・永続化・JSON入出力・プラン管理。
- **フェーズB（実装済）**: 日射シミュレーション。
  - `js/sun.js` に NOAA 準拠の太陽位置計算（外部ライブラリ不使用）。`getSunPosition(date, hour, lat, lng)`。
  - 3Dビューで `DirectionalLight` を太陽位置に連動・影（shadow map）を有効化。`site.azimuth` を建物回転に反映。夜間は太陽光を消灯。
  - 日射UIパネル（日付/時刻スライダー・季節クイック移動・太陽情報・1日アニメ再生・緯度経度/方位角）。
  - 各部屋の直射日照時間を `Raycaster` で集計し、2Dの部屋ラベルに「☀ 5.5h」表示。座標既定は板橋区赤塚（北緯35.775 / 東経139.679、`meta.lat`/`meta.lng`）。
- **フェーズC**: 建具/住設/外構の充実、敷地写真の下絵トレース、壁の手動編集、寸法線、PDF/画像書出、kWh単位の取得熱量概算。
