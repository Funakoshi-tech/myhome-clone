Car Kit GLB Pack - 50 Free CC0 3D Models

This is a GLB-ready convenience package based on Car Kit / Kenney.

Included:
- 50 GLB files in models_glb/
- Matching PNG reference renders in reference_png/ when available
- MODEL_LIST.csv
- Original Kenney license text
- Source and license verification notes

Intended use:
street scenes, parking lots, traffic backgrounds, vehicle props, accident scenes, game prototypes, and Clip Studio Paint background reference.
